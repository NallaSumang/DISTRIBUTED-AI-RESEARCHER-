## ⚡ The Architectural Vision

Built from the ground up by **Sumang**, this project abandons the limitations of traditional, single-threaded chatbots. It is designed to act as a **Neural Swarm**—deploying multiple asynchronous AI agents simultaneously to conquer massive research topics in seconds.

This is not a prototype. It is a highly optimized, decoupled architecture that pairs raw Python computing power with a breathtaking Next.js 3D UI.

---

## 💎 Elite Tech Stack

### 🧠 The Backend Engine (Swarm Control)
- **FastAPI (Python):** Chosen for its unmatched ability to handle multi-threaded AI processing without blocking the main event loop.
- **Upstash Redis:** Acts as a high-speed message broker. Instantly catches and queues incoming HTTP requests, preventing 504 Timeouts and server crashes during massive 60-second AI generation loads.
- **Supabase (PostgreSQL):** Permanent cloud storage. Every research report is structured, indexed, and immortalized in the cloud.
- **Concurrent Futures:** Spawns physical background threads to deploy multiple Tavily Search API agents simultaneously.

### 🎨 The Frontend (Neural HUD)
- **Next.js 15 & TailwindCSS:** Lightning-fast rendering combined with utility-first styling.
- **3D CSS Engine:** The background features a purely CSS-rendered 3D Cyber-Grid. By using `rotateX(60deg)` and mathematical linear gradients, it creates a 60FPS optical illusion of an infinite, aggressive digital floor without draining laptop batteries.
- **Asynchronous Polling:** The React UI intelligently polls the Redis queue, seamlessly rendering the final Markdown report the exact millisecond the Python Swarm finishes its work.

## 🚀 Deployment & Usage

### 1. Ignite the Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
# (In a separate terminal, start the queue worker): 
python worker.py
```

### 2. Launch the Neural HUD
```bash
cd frontend
npm install
npm run dev
```
